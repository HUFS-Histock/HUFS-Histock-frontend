## 반영한 화면

기본 120일 차트 → 보조지표 선택 → AI 위험 패널 → Top 5 호버 → 좌우 분할 → 단일 차트 복귀. 각 단계에서 캔들/선 전환을 유지합니다. 단일 20일의 캔들과 거래량 폭은 날짜 칸의 70%이며, 선 차트 호버에서도 거래량 폭을 유지합니다. 분할 화면은 기존의 좁은 폭을 사용합니다.

데스크톱에서는 왼쪽 종목/시세, 오른쪽 차트 및 분석을 유지합니다. 2026-11-06 수정으로 분할 비교에서도 왼쪽 바와 오른쪽 패널의 위치·너비를 유지하며, 오른쪽 패널 내부만 두 차트로 나눕니다. 모바일에서는 종목 요약을 위로 옮기고 위험 지표와 분할 차트를 세로로 배치합니다. 과거 사례 표는 가로 스크롤됩니다.

## 실제 데이터에 맞춘 차이

- 지원하지 않는 종목 검색, 주/월봉은 사용 가능한 기능처럼 표시하지 않습니다.
- `1개월/3개월/6개월` 대신 실제 제공되는 `20/60/120거래일`로 표시합니다.
- 분석 날짜/방식 및 오류·데이터 지연·출처 안내를 추가했습니다.
- 현재가 영역은 실시간 시세가 아닌 저장 종가라고 표시합니다.
- 전체 기간의 가격 API가 없어 저장본에 없는 날짜는 분석 응답의 상대 수익률 선만 표시하고 거래량은 미제공으로 안내합니다.
- 저장 예시는 명시적으로 선택할 때만 분석 결과를 대체합니다. 라이브 요청 실패 시 자동으로 저장 분석을 보여주지 않습니다.

## 확인한 동작

Chrome에서 5개 사례의 호버/이탈, 포커스/Enter, 클릭/분할, Escape/복귀, 캔들/선, 20/60/120일 조회 및 확대/축소를 확인했습니다. 실제 날짜 변경·휴장일 보정·검색 방법 변경·과거 사후 관측·최신 미관측과 429/오류/빈 결과도 검증했습니다.

Figma 프로토타입 자체의 동작 및 Safari/Firefox는 이번 작업에서 검증하지 않았습니다.

## 2026-11-06 차트 호버 표시

파란 점 대신 가로·세로 점선을 표시합니다. 오른쪽 회색 라벨은 마우스 높이에 해당하는 가격(정규화 화면은 지수), 거래량 아래 회색 라벨은 선택한 거래일입니다. 거래량에 호버하면 날짜와 세로 점선만 표시합니다. 실제 날짜를 제공하지 않는 상대 흐름은 D 단위로 표시하며, 마우스 이탈 시 라벨을 지웁니다.

Chrome에서 가격 축 값·세로 이동·하단 날짜 위치·마우스 이탈·선 전환·분할·모바일 경계를 확인했습니다. 기존 시나리오 포함 브라우저 검증 5개와 빌드·린트가 통과했습니다.

시세 요약은 이동평균 위에 `시 / 고 / 저 / 종 / 전 거래일 대비 등락액(등락률) / 거` 순서로 표시합니다. 호버한 일봉으로 갱신하고, 이탈하면 구간 마지막 일봉을 표시합니다. 상승은 빨간 ▲, 하락은 파란 ▼, 보합은 중립색이며 등락률은 소수점 두 자리입니다. 이전 거래일 가격이 없으면 등락은 `—`로 표시합니다. 이동평균의 계산·색상·선은 변경하지 않았습니다.
