# HISTOCK Frontend

SPY 차트와 과거 유사 국면을 살펴보는 React · TypeScript · Vite 웹 화면입니다.
사용자가 전달한 2026-11-05 Figma PNG와 기존 로컬 차트 시안을 기준으로 구현했습니다.

## 실행

Node 24 이상과 Chrome을 사용합니다. 형제 저장소의 FastAPI(8000)와 Spring Boot(8080)를 먼저 실행합니다.

```sh
npm ci
npm run snapshot
npm run dev
```

브라우저에서 <http://127.0.0.1:5173/>를 엽니다. `/api`는 Vite 개발 프록시를 통해 Spring Boot로 전달됩니다. 브라우저에서 FastAPI나 외부 시세 업체를 직접 호출하지 않습니다.

`npm run snapshot`은 형제 AI 저장소의 `.venv`/pandas 및 기존 `data/raw/price_SPY.parquet`, 실행 중인 백엔드가 필요합니다. 외부 시세 다운로드나 모델 재학습은 하지 않습니다. 최신 분석 결과, 현재 240거래일(120일 이동평균의 선행 데이터 포함), Top 5 각 20거래일을 `public/snapshot.json`에 저장합니다. 이 파일은 Git에서 제외됩니다.

저장본 없이도 백엔드 분석은 동작합니다. 이때 캔들·거래량 대신 API의 누적 수익률 선과 시세 미제공 안내가 나옵니다.

## 화면 사용

1. 기본 차트는 저장된 120거래일입니다. 20/60/120거래일, 확대·축소 버튼, 캔들/선 전환을 지원합니다. 확대·축소는 조회 기간 전환이며 휠 줌/드래그 이동은 포함하지 않습니다. 주봉·월봉은 비활성화되어 있습니다.
2. `보조지표`에서 변동성·급락 위험·수익률 범위를 선택하고 `차트에 AI 분석 추가`를 누르면 바로 20거래일 차트와 상단 Top 5가 나타납니다.
3. 날짜와 검색 방식을 선택해 실제 API를 호출합니다. 모델 입력과 사후 분석은 모두 20거래일입니다. 차트의 60/120일 조회와 모델 기간은 별개입니다.
4. AI 보조지표를 추가하면 Top 5 버튼이 바로 나옵니다. 다른 조회 기간으로 바꾼 뒤에는 `차트로 비교하기`로 다시 열 수도 있습니다. 버튼/표 날짜의 호버·키보드 포커스는 시작값 100으로 정규화한 겹쳐 보기, 클릭·Enter는 과거/현재 분할 비교입니다. Escape 또는 `단일 차트로`로 돌아갑니다.
5. 서버 장애 시 오류와 재시도를 표시합니다. `저장된 예시 보기`를 직접 누른 경우에만 저장된 분석을 표시하며, API 결과인 것처럼 자동 대체하지 않습니다.

## 데이터 경계

- **실제 연동:** `/api/v1/analysis/health`, `/methods`, `/search`. 지원 날짜 범위, 실제 분석일, 방법, 사례, 위험 지표, 실제 사후 결과를 검증해 표시합니다.
- **시세는 로컬 저장본:** 현재 백엔드에는 OHLCV API가 없습니다. 저장본의 날짜가 분석 기준일과 정확히 맞고 연속 구간이 존재할 때만 캔들/거래량을 제공합니다. 전체 화면의 날짜와 출처를 표시합니다.
- 다른 날짜의 시세로 대체하거나 `query.path`에서 가짜 OHLCV를 만들지 않습니다. `spy_cum_return`은 상대 흐름만 표시하는 용도로 사용합니다.
- 변동성은 연율화, 수익률/확률은 소수 → 퍼센트 변환, 유사도는 점수로 구분합니다. HAR-X와 사례 기반 변동성, 급락 추정값과 기준 비율을 구분합니다. null은 미관측/미제공이며 0으로 바꾸지 않습니다.
- 현재 데이터가 늦으면 `stale` 안내를 표시합니다. 예전 날짜의 고정 모델 학습 시점 한계도 안내합니다.
- 2026-11-05 실행 시 API 데이터 종료일은 2026-11-02였습니다. 실시간 시세 연동은 아직 없습니다.

## 검증

```sh
npm test
npm run lint
npm run build
npm run test:e2e
```

브라우저 테스트에는 실행 중인 AI/백엔드와 로컬 저장본이 필요합니다. Vite는 테스트가 자동 실행하거나 기존 5173 서버를 사용합니다. 일반 흐름은 실제 API, 로딩/429/빈 결과/잘못된 응답/연결 실패는 명시적인 테스트 응답을 사용합니다.

2026-11-05 검증 결과: 단위 검증 10개, Chrome 브라우저 시나리오 4개, TypeScript/프로덕션 빌드/Oxlint 통과. 백엔드의 `python3 scripts/verify_integration.py`도 실제 AI 응답과 12개 항목 비교를 통과했습니다. Chrome 1600px와 390px에서 기본·호버·분할·모바일 화면을 캡처해 확인했습니다. 캡처와 실패 trace는 Git에서 제외한 `test-results/`에 저장됩니다.

## 구조

- `src/App.tsx`: 조회 상태, 지표 선택, 날짜/방식, 차트 비교 화면
- `src/api.ts`: 런타임 응답 검증, 요청 취소·시간 초과·오류 메시지
- `src/chart.ts`: 기간 조회, 정규화, 이동평균, 캔들·거래량 공통 좌표
- `src/components/Chart.tsx`: React SVG 가격/거래량 차트
- `src/components/AnalysisPanel.tsx`: 위험 요약·과거 사례·실제 결과
- `e2e/`: 실제 API와 제어된 장애 응답을 사용하는 브라우저 검증
- `docs/design/HANDOFF.md`: 디자인 출처와 반영 범위

## 배포 전 남은 작업

로컬에서 실행한 상태이며 공개 배포·커밋·푸시는 하지 않았습니다. `npm run build`는 로컬 시세 저장본을 배포 파일에서 제외합니다. 배포 환경은 `/api`를 Spring Boot로 연결해야 하며 Vite 개발 프록시는 배포 시 적용되지 않습니다.

실시간/전체 날짜 OHLCV API, 외부 표시·보관·분석을 허용하는 데이터 이용 권한, 공개 서버의 요청 제한·운영 설정을 별도로 준비해야 합니다. Figma MCP 한도로 최신 노드의 직접 조회·픽셀 단위 대조는 하지 못했고, 제공된 PNG로 시각 확인했습니다.
